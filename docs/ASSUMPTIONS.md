# Decisions and evidence limits

**Documented** means operator behaviour or specifications found in Rev. F. **Inferred** identifies a decision resolving incomplete instructions. **Simulator substitute** identifies an independently designed mechanism. **Unknown** records missing knowledge. **Physical/non-software** covers hardware-only properties. See the requirement map for individual test references.

| Issue and evidence | Decision and alternative |
|---|---|
| Identity and chronology | The fixed baseline is Rev. F (1991). The supplied photographs and Crypto Museum observations inform geometry and the four groups of eight letters. Reported 1992 firmware v1.6.9 is a separate observation. The startup banner identifies the reconstruction. No firmware binary or evidence tying this specimen to a particular British configuration was supplied. |
| Main menu count, p. 9 | The text says 14 but enumerates 13. Implement the listed 13; ZRO remains a physical key. |
| Slot confirmation, pp. 6–9 | Use two digits and ENTER as in the explicit example on p. 9. Each visible page contains four slots. Empty names are rejected. |
| Slot name after acceptance, p. 8 | Show the accepted name despite the AVAILABLE example illustration. Rejected material never becomes active. |
| First activation, p. 5 | Require ten digits and fifteen letters in two fields, D CH to correct, ENTER after each. Their purpose and original validation remain unknown. Factory reset also marks the clock unset. |
| Confirmation and notices | Y within 15 seconds starts; N/XIT cancels. Other keys do nothing at the power question. Training startup takes 350 virtual ms. Short notices last 420 ms and the next key can advance them. Explicit warnings need dismissal. Screen spacing and some long prompts are adjusted to forty cells. |
| Buffers and capacity | Plain capacity includes LF after a nonempty classification and all paragraph breaks. Cipher text permits 4184 base32 symbols for the largest training envelope. Group spaces are presentation. This models logical message capacity separately from unknown hardware packing. Input beyond capacity produces a warning. Oversized pastes are refused as a whole; the existing text remains intact. |
| Search, movement and commit | Forward search starts at cursor, has no wrap and leaves the cursor after a hit. BOT restarts from the beginning. A failed search leaves the cursor intact. Soft wrapping indexes original content, including the wrapping space. Up/down clamp the preferred column to the target line; at a soft-wrap boundary the insertion point belongs to the following line. D WD consumes leading whitespace then the next non-whitespace run. XIT commits edits. |
| Key and authentication substitutes | The original algorithms, validation and key update are unknown. CRYPTO_SIMULATION.md defines the exact DES-based format, key/check functions and 20-minute boundary. Ordinary message keys are independent of time. Authentication examples on pp. 41–42 read 3F6X and 376X. The reply paragraph describes reading a challenge; the surrounding procedure requires communicating the reply. These examples are not vectors. |
| Receive space | Auto-select A before B. If both occupied, N aborts without change. Y alone clears nothing; selecting A/B clears that buffer immediately. Aborted reception after that never restores earlier content. No partial ciphertext commits. |
| Radio medium and FEC | Each frame carries ASCII cipher symbols with a big-endian CRC-32 prefix. Repeat each byte three times. Receive uses bitwise majority then validates CRC. A deterministic LCG (multiplier 1664525, increment 1013904223, modulo 2^32) advances once per transmission; its value chooses a triplet and bit. Correctable flips one copy, burst flips the same bit in two. Drop prevents acquisition; carrier loss and overlapping transmissions invalidate reception. These are distinct controlled impairments rather than measured RF probabilities. No encryption keys or plaintext travel through the medium. |
| Rate, variants and timeouts | Airtime is 400 ms plus ceil(1000 × encoded bytes × bits per byte / rate). Digital uses 11 bits per byte. Audio uses 8 as an abstraction at 300 baud. U/E settings remember a telephone-line choice; analogue profiles are otherwise identical. A listener times out after 120 virtual seconds without acquisition. Local completion is possible with no listener. Reuse Y reuses path and direction; reconfirm buffer, acoustic line and digital speed where applicable. |
| Printer p. 46 vs Appendix B | Use the detailed Y-to-release rule, not the generic “press a key”. P/L/F require printer attachment. Output advances one character per 25 virtual ms. XIT during or after print returns to printer options, then XIT leaves. The printout can outlive a key or buffer. |
| CLK, calendar, RTC | Temporary clock display returns on the next key. It is inhibited during active TX/RX, transforms and reply generation. Gregorian UTC, 1970–2099 for editable dates, weekday derived, month-end clamped, seconds reset on S/XIT. Drift and clock acceleration are bench settings. |
| ZRO precedence | ZRO can interrupt processing, reception and printing. A generation change cancels pending work; no result can overwrite a confirmed erasure. At the startup banner it offers all-key confirmation directly. No cancellation erases committed buffers. A malfunction erases keys but retains committed messages. |
| Contrast and held reset | UP held with SRCH sets maximum contrast. ↑ at the first slot page restores contrast and pages backwards; V gives the regular adjustments. The substitute held-XIT reset threshold is two seconds. A persistent injected fault repeats on the next self-test. |
| Retention and power | Normal off and main-cell replacement retain committed RAM and quiet mode; the backup/RTC description supports this inference. An unfinished editor transaction is lost. Factory reset is a separate bench action clearing the simulated retained state. Reload starts a fresh training setup. No key storage, automatic restore or forensic erasure guarantee. |
| Source and asset attribution | Primary reference: supplied TRW KL-43C Operator's Manual, 410-308-1 Rev F (15 August 1991). Geometry: five supplied Crypto Museum KL-43C photographs, including front panel and case/connector views. No source photos or full manual redistributed. The PRC-319 and its EMU are distinct devices. Source conflicts about weight, batteries and adaptor arrangements are resolved in favour of Appendix F for this baseline. Independent bench measurements and original RF framing remain unknown. |
