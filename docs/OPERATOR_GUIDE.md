# First exchange quick reference

From the bench's starting configuration, slot 01 on each device holds matching training material. Select **Operating manual** inside the app for searchable, printable guidance.

| Device | Keys | Check before continuing |
|---|---|---|
| Both | SRCH, Y, wait, 0, 1, ENTER | Main menu shows W and Q |
| Terminal 1 | W, A, P, ENTER, type TEST MESSAGE, XIT | Stored As Message A |
| Terminal 1 | E, A, Y, Y | Main menu returns |
| Terminal 2 | C, A, C, R, ENTER | Waiting for Carrier... |
| Terminal 1 | C, A, C, T, A, ENTER | Transmission Complete on each unit |
| Both | XIT | Main menu |
| Terminal 2 | D, A, Y, Y; then R, A | TEST MESSAGE |
| Terminal 2 | XIT, attach Printer, P, A, P, Y | Read the paper output |

Select **N** if an earlier communications setup is offered and you want to enter the complete sequence. To enter a new key, use K, choose an empty two-digit slot and ENTER, type its name and ENTER, then copy each group from the external Training key card followed by ENTER.
