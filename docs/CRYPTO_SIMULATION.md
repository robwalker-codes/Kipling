# KL43_SIM_DES_CFB8_V1

This educational substitute has no hardware interoperability or confidentiality assurance. Its inputs and wire format are local simulator conventions.

* Training entry consists of 31 letters A–Z and a check letter. Number A=0 through Z=25. The check letter is the sum of the first 31 values modulo 26. The factory-issued training example is ABCDEFGH IJKLMNOP QRSTUVWX YZABCDEX.
* Hash the ASCII string “KL43/1/” followed by the 32 letters, slash, and the decimal update level (no leading zeros) with FNV-1a-64. Use its unsigned eight-byte big-endian result as a single DES key. DES ignores parity bits. Slot number, name, clock and device identity do not enter the calculation. Key changes can collide in this finite educational key space. An update increments the level, bounded at 99. No wrap.
* Message bytes are ASCII. A nonempty classification is the first line, followed by LF and the body. That LF counts toward the 2600 characters. The uint16 big-endian byte length and four-byte big-endian IEEE CRC-32 of the message precede the message inside the encryption. DES-CFB8 uses the first byte of DES encryption of the current register as its keystream byte. Shift in the ciphertext byte after every octet in either direction. The initial register is eight fresh random bytes per encryption.
* The envelope is byte 01, the eight IV bytes, then encrypted length/checksum/message. All bytes enter RFC 4648 base32 MSB first, no equals signs. Unused final bits are zero. Display groups contain three symbols, except the final group may contain one or two. The decoder checks canonical encoding, version, exact length, permitted characters and CRC. CRC detects errors and offers no cryptographic authentication. At maximum size 2615 envelope bytes yield 4184 symbols. A typed ciphertext buffer allows the full expansion, excluding separators.
* Verbal challenge uses four base32 symbols (20 bits). The upper 15 bits store whole UTC seconds modulo 32768, the lower five are random. Reply recovers the nearest matching second relative to its own RTC. Within an inclusive 1200 whole seconds, use that recovered second. Outside the window use the bitwise complement of the recovered second. The DES input block is the unsigned 64-bit big-endian low bits of (signed second × 32 + nonce); take the first 20 output bits as the reply. Replays within the window can match. Across modulo rollover the recovered absolute second contributes to the result. Four-character replies inherently admit accidental collisions. No endpoint reads the other clock or key.
* The supplied FIPS 81 Appendix D Table D2 vector is checked in both directions and cross-checked against OpenSSL's legacy DES-CFB8 implementation. The original NIST-hosted PDF was unavailable from this machine. Standard DES block vector: key 133457799BBCDFF1, input 0123456789ABCDEF, output 85E813540F0AB405. The primitive implementation is des.js (MIT). These vectors test the substitute only.
